Behaviour of each state

  • Short term: under 2 characters the panel shows the hint and sends no request (R3). The hint is a polite live region.
  • Loading: shown after the 250 ms pause, only if the answer takes longer than 150 ms, so quick searches never flash a skeleton. Rows match the real row height (52 px) so the panel does not jump. The previous results are replaced, never mixed with the new ones; an answer for an older term is dropped (R8). The field keeps aria-busy="true". The shimmer stops with reduced motion and shows flat blocks.
  • No results: says what was searched and what to try; the one action clears the field and returns focus to it.
  • Error: one calm banner with role="alert", plain cause, and "Try again" as the single primary action; focus moves to it. The typed term is never cleared. If the role cannot see a type at all, that type is absent and is not an error.
  • Dark: error colours reuse the CRM's banner-error dark values (#450a0a, #fca5a5, #7f1d1d). The primary button uses the lighter bank accent with dark text so it reads at 4.5:1 or better.
