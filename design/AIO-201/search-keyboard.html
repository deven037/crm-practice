Global search: keyboard map and screen reader announcements

The search follows the ARIA combobox pattern with a listbox popup. Focus stays in the input the whole time; the highlighted result is exposed with aria-activedescendant. Epic AIO-199, rule R7 (and AIO-124).

Keyboard map

Pressed again with the panel open, it closes the panel and returns focus to the opener. The browser's own shortcut is suppressed.

↑Results shownMoves up one row; from the first row it wraps to the last. Focus stays in the field.

EnterNo row highlighted, term has 2+ charactersOpens the Leads list filtered by the term if Leads is the first type with results, otherwise the first type that has results.

Home EndField focusedMove the caret in the text, as in any input. They do not change the highlighted row.
TabPanel openCloses the panel and moves to the next control (the clear button, then the theme toggle). Rows are not tab stops. The error panel is the exception: it stays open while Tab moves through "Try again" and "Close", and closes on "Close", Esc or Tab past "Close".
Enter or Space"Try again" focusedRuns the search again with the same term; focus stays on the button while it works.

Focus return

  1. OpenCtrl or ⌘ + K stores the previously focused element as the opener.
  2. UseFocus stays in the input. Mouse clicks on rows do not take focus away from it.
  3. CloseEsc (twice), a picked result or a second Ctrl or ⌘ + K puts focus back on the opener. If the opener is gone after navigation, focus goes to the page's main heading.

Markup rules for Alex

  • The input has role="combobox", aria-expanded, aria-controls (the listbox id), aria-autocomplete="list" and aria-activedescendant. Keep data-testid="global-search" on the field.
  • The highlighted row shows the selected style (tint, 3 px accent bar, solid tile) from the mockup, and has aria-selected="true"; nothing relies on colour alone, because the bar and tile change shape and fill.
  • Rows that hide Email or Phone for the user's role must not contain that text in the DOM either, so a screen reader cannot read it (R6).
  • The focus ring is the 2 px outline on the field plus the bank-tinted halo, kept on in both themes. Targets are 52 px rows on desktop and 56 px on phone.
