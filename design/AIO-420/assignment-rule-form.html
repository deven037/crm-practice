Build notes

Layout

One 880 px column. Two surfaces: details, then conditions. Save and Cancel sit in a bar above the form, as today (Save is the single primary). Labels above inputs, 44 px controls. Priority gets a helper line.

Conditions

Each condition is a row of Field, Operator, Value and Remove, with “and” between rows, because every condition must match. Value stays a select, true/false select or input by field kind. Changing Module resets conditions, as today. “+ Add condition” becomes “Add condition”.

Kept as is

Validation logic, toast text, redirects after save. Hooks: assignment-rule-form-page, assignment-rule-name, -module, -assignto, -save-btn, -condition-field-N, -condition-value-N. Inline errors are new and show only after Save is pressed. Priority must be a whole number of 1 or more (the code uses Number(value), which can give 0 or NaN). Zero conditions blocks Save. One error channel: inline plus toast, no banner.

390 px

Single column, Save above Cancel, full width, 44 px. Condition rows stack with Remove under them. No horizontal scroll (the old table scrolled).
