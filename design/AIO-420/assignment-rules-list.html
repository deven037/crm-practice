Build notes

What changes

The card gallery becomes one ordered list, because priority order is what the page is about. Each row: priority circle on a connecting line, name, a one-line summary of conditions and assignee, module and Active pills, Delete. Sorted by priority ascending (ties keep stored order). The dashed “create tile” becomes the header button and the empty state; label stays “New Rule”.

Kept as is

Route, copy of the intro, row opens /setup/assignment-rules/:id, Delete asks window.confirm with the same text and shows the same toast. Hooks: assignment-rules-page. Rep/viewer rule: user.role !== 'admin' hides create and delete.

Tokens and a11y

Circle fill is --bank-primary with --bank-on text; inactive is neutral. Pills are never colour only (the word is shown). Row link and Delete are separate tab stops, 44 px on phone. Focus ring 2 px --text.
