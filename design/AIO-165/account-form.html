Saving

Fields lock, button disabled so a second click can’t submit twice. Announced as “Saving account”. Edit mode says “Saving…” on “Save changes”.

Save failed

One calm banner above the footer; every value stays. If the server refuses (viewer): “You don’t have permission to change accounts.”

Validation timing

Errors show after a field is left or after the first submit. Focus moves to the first invalid field, which reads its error through aria-describedby. The red bar and “!” icon mean colour is never the only signal.

Edit mode

Title “Edit Northquay Logistics”, fields prefilled, primary button “Save changes”, Cancel discards and returns to the record. Custom fields tab appears only when the bank layout defines any; required custom fields use the same error pattern.

Roles

Admin / rep: can open this screen.

Viewer: no New Account or Edit entry points; a typed URL ends in the Forbidden state from the shell design (AIO-140).

Responsive

Two columns at 1440; one column under 780 px (768 and 390 alike). Footer buttons stack full width with Create account on top, 44 px tall, 16 px gutters.
