Build contract

Initial load and Retry: mark only the task region busy; disable quick-add and filters until resolved. Keep the selected filter and any typed draft. A rejected request or proposed 10-second timeout exits loading into the error frame. Cancel or ignore older responses so they cannot replace a later result. Retry starts one request; further activation is ignored while pending.

Keep Retry mounted and focusable with aria-disabled while loading. Failure returns its label to Retry without moving focus. Success removes it and focuses the active filter, then announces “Tasks loaded.” once in a polite status region. An empty successful response uses AIO-292’s per-filter empty states, never this error frame. The loading status region sits outside aria-busy so the announcement is not deferred.

All roles can load, filter and retry. Viewer has no quick-add or mutation controls; recovery is identical. At 768 and 390 px use the AIO-140 shell overlay, hidden by default; Open navigation invokes its overlay and focus rules. This static mockup does not implement navigation.
