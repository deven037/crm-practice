Error

There is no error state. The component reads local data and renders static links (Verified). If the store cannot be read, the hook returns its default empty list, so the empty state above applies. Page-level load errors (Deals, Tickets, Contacts record) appear below the panel and do not hide it.

Decisions for Morgan

  1. Phone folding. Approve the 48 px disclosure headings with ToolBox folded by default, or keep both zones open. Leads on a phone is about 520 px tall when both are open.
  2. Viewer. Keep showing all links to viewers, who land on Forbidden (today and the design), or hide or mark them. Both are small. Changing it needs a Decision, like D1 for SLA in AIO-416.
  3. Deleted records. Extend the Contacts behaviour (remove the row on delete and on "not found") to the other seven modules. It touches seven detail pages, so it is Alex's build step, not styling.
