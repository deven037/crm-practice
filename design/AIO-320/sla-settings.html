How it works

Fixed rows

Exactly four rows, Urgent to Low, only hours editable; no add or delete (AC9). Row descriptions are new helper text.

Validation

Hours must be a number above 0, otherwise the field gets the inline message and a toast “Enter a valid number of hours.”; nothing saves (AC20). Success toast: “<Priority> SLA set to <n>h.” and the value persists (AC17).

Roles

Admin edits. Rep: read-only, as the screen does today. Server still accepts rep writes; this is a screen-only restriction (Assumption from AIO-185; flag for Alex and Casey). Viewer: read-only.

Responsive and bank

390: each row stacks: priority, hint, hours field, full-width Save (44 px). Save fill follows the bank colour; priority pills keep meaning colours. Hours are plain clock hours; business hours are not modelled.
