How it works

Reading a row

Priority, status and “Breached” are words first, colour second (AC33). Status carries a symbol (○ ◐ ✓ ■). The selected row gets a bank-colour edge and a lifted surface, and is marked aria-current.

One SLA meter

The same thin meter shows on the pane and record: bank fill while time remains, red with “SLA breached” when over. Resolved and Closed show “SLA not applicable (ticket isn’t active)” and no bar.

Responsive

1440: list 440 px + pane. 768: overlay navigation, list 300–360 px beside the pane. 390: list only; choosing a row opens the record page (see ticket-record) with “‹ Tickets” to return. Chips scroll sideways inside their own strip.

Pane equals record (AC5)

The pane shows everything the record page shows, in the same order: status, Delete ticket, SLA, requester, editable priority, description, Move to, custom fields, attachments, comments and composer. Both render the same shared component. Delete opens the same dialogs (ticket-states). A failed change shows the same recovery (ticket-states).

Roles

Admin and rep: all controls. Viewer: same pane, but New Ticket, Move to, Delete, priority, custom fields, Attach file, comment box and canned responses are disabled with a “View only” hint (see ticket-states). Comment Edit and Delete show only on your own comments. Assumption closing Avery’s open question.

Open + In Progress filter

The dashboard link /tickets?status=open opens with this chip selected and lists the 5 active tickets. Selected state:

Open + In Progress 5All 7Open 3

Empty result reads “No tickets with status “Open + In Progress”.”

Keyboard

View toggle, New Ticket, shortcut links, chips, then each row (Enter opens it in the pane), then the pane’s Move buttons. Focus ring is 2 px --text.
