List view

Switch and persistence

Board and List are one pair of toggle buttons (aria-pressed); the choice is kept in the address (?view=list) so a refresh or shared link opens the same view. The “Open deals” stage option matches the Dashboard link (?stage=open).

Columns, sort, filter

Deal, Account, Stage, Amount, Probability, Expected close, Owner, as AC3 asks. Sorting and filtering work in the browser on the loaded deals, so no API change. Header buttons set aria-sort. Assumption: AC3 left columns, sort and filter undecided; this is the proposal.
